# Hoja de Vida Personal - HTML & CSS

Proyecto de la Tarea 2 (CSS): página web de hoja de vida personal construida con HTML5 semántico y una hoja de estilos CSS externa, usando contenedores `<div>` para organizar el contenido.

## Estructura del proyecto
```
hoja-de-vida/
├── index.html      # Estructura y contenido de la página
├── style.css       # Hoja de estilos externa
├── img/
│   └── foto-perfil.jpg
└── README.md
```

## Cómo verla
Abrir `index.html` en cualquier navegador (no requiere servidor).
