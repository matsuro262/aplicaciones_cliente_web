# Registro de Estudiantes (HTML, CSS y JavaScript)

Página web para registrar estudiantes (cédula, apellidos, nombres, dirección, teléfono,
correo electrónico, facultad, nivel y paralelo).

- Validaciones con expresiones regulares en JavaScript.
- Almacenamiento local en formato JSON usando localStorage.

Para ejecutarlo, abrir `index.html` en el navegador.
